# Signature Studio

Create email signatures in minutes. Customize, preview, and copy directly into Gmail, Outlook, Apple Mail, all in your browser with no account required.


## Features

- **No account needed** — Everything runs in your browser. Your data stays private.
- **Multiple templates** — Choose from Classic, Profile, Minimal, Corporate, Founder, Creator, and more.
- **Full customization** — Add your photo, logo, contact details, social links, colors, fonts, and spacing.
- **Live preview** — See exactly how your signature will look in an inbox as you build it.
- **Email-safe HTML** — Generates clean, inline-styled markup that works across major clients.
- **Copy & export** — Copy as rich text, raw HTML, or plain text. Export a vCard or backup your profile as JSON.
- **Built-in checks** — Compatibility lab flags common issues like HTTP links or non-inline styles.

## Getting Started

### Use it online


### Run locally

```bash
# Clone the repo
git clone https://github.com/your-username/email-signature-builder.git
cd email-signature-builder

# Install dependencies
npm install
# or
pnpm install
# or
yarn install

# Start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## How it works

1. **Choose a template** — Pick a layout that fits your style.
2. **Add your details** — Fill in name, title, contact info, photo/logo, and links.
3. **Design & refine** — Tweak colors, typography, and spacing to match your brand.
4. **Copy and use** — Copy the signature and paste it into your email client.

## Privacy

All data is stored locally in your browser via `localStorage`. Nothing is sent to a server.
